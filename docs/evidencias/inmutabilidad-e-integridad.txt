## 2. aud_app (rol de la API) no puede modificar ni borrar: falta el permiso

$ psql -U aud_app -c 'UPDATE audit_logs SET severity = 0 WHERE id = 3'
ERROR:  permission denied for table audit_logs

$ psql -U aud_app -c 'DELETE FROM audit_logs WHERE id = 3'
ERROR:  permission denied for table audit_logs

$ psql -U aud_app -c 'TRUNCATE audit_logs'
ERROR:  permission denied for table audit_logs
